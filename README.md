# ポートフォリオLP

## GitHubリポジトリ

https://github.com/hikari622192-tech/portfolio

## 構成

- `index.html`：自己紹介、経験・スキル、制作例への案内。CSS・JavaScriptを含む静的HTML。
- `assets/mascot.webp`：既存キャラクター画像。
- `design/`：既存の画像・資料制作ポートフォリオ。

事務・資料作成・データ整理・Web更新など、PC作業の参考資料として役立つ応募で使う。すべての募集業務への対応や受託実績を示すものではない。

カードのホバー・スクロール表示と、資料／画像／Web記事のプレビュー切り替えを実装。スマートフォンではホバー操作を必要とせず、動きを減らす設定にも対応する。

## 更新方法

1. `index.html` を編集する
2. リポジトリ内で表示・リンクを確認し、対象ファイルだけをコミットする

```
git add index.html assets/mascot.webp README.md
git commit -m "Update portfolio LP"
git push
```
